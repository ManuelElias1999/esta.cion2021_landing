# Estación de uñas · by Dani Velasquez

Landing page de **Estación de uñas** — especialista en uñas acrílicas en Cochabamba, Bolivia.

- Reserva de citas (bloques de 1 h 30 min) que se envían por WhatsApp.
- Mano interactiva: pasa el cursor (o toca) las uñas para pintarlas.
- Tienda de productos con carrito y pedido por WhatsApp.
- Servicios, ubicación (mapa) y redes sociales.

Sitio estático (HTML + CSS + JS), sin dependencias. Abre `index.html` o publícalo con GitHub Pages.

## Editar contenido
En `script.js`, al inicio:
- `HORARIOS`: horarios de atención por día.
- `SERVICIOS` y `PRODUCTOS`: nombres, descripciones y precios (`null` = "Consultar").
- `WHATSAPP`: número para reservas y pedidos.
